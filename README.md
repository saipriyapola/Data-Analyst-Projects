# HR Analytics Project 

Analyzed employee data across departments, gender, age, salary, and performance.  
Cleaned and transformed raw data using Power Query, then built relationships and DAX measures.  
Designed dashboards to answer 10 HR scenarios including workforce distribution, salary gaps, and performance trends.  
Compared employees across countries (India vs New Zealand) for insights on growth and pay.  
Delivered clear visuals that help managers make better decisions in hiring, promotions, and salaries.  
Showcased end‑to‑end HR analytics workflow from raw data to actionable insights.
